# DuckDuckGo YouTube Content Blocker Extension

An MV3 browser extension that supports YouTube ad blocking in DuckDuckGo browsers. It loads a limited subset of content blocker scriptlets imported from [uBlock Origin Lite](uBOL), which we prune to only include arguments for the targeted sites.

Any issues with the feature itself are best reported via our in-browser form. Click on the shield in the URL bar, then "Report a problem with this site". For more general feedback, check out our [contact page](https://duckduckgo.com/duckduckgo-help-pages/company/contact-us).
