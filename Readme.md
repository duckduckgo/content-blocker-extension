# DuckDuckGo Content Blocker Extension

A MV3 browser extension that loads a limited subset of content blocker scriptlets,
targetting a specific subset of sites. Scriptlets are imported from [uBlock Origin Lite](uBOL),
then pruned to only include arguments for the targeted sites.

The extension and scriptlets are licensed under GPLv3.

[uBOL]: https://github.com/uBlockOrigin/uBOL-home/tree/main
